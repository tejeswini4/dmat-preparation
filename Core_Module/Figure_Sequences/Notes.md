1. Rotation Logic ⭐ (Most Important)

A figure changes its direction by rotating.

Types of rotation:
Clockwise Rotation

Movement:

      ▲
      |
◀ ----+---- ▶
      |
      ▼

Example:

▲ → ▶ → ▼ → ◀ → ▲

Rule:

Every step = rotate 90° clockwise
Anti-clockwise Rotation

Example:

▲ → ◀ → ▼ → ▶ → ▲

Rule:

Every step = rotate 90° anti-clockwise
Other angles:

Possible rotations:

45°
90°
180°
270°

Example:

↗ → ↘ → ↙ → ↖

Rule:

Rotate 90° clockwise
How to identify rotation:

Ask:

Is the same shape present?
Is only direction changing?
Does it turn by equal angles?

If yes → Rotation pattern.
